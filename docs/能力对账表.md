```
你真的做了 → 但没挂名词 → 开口时自动降级（"只是简单做了…"）
          → 对方归到"跟教程跑过一遍" → 最后自己也信了
```

同一件事，两套说法，一档之差。这张表就是把两套说法对齐。

## 一、术语对账

### ① 检索（RAG）— `lib/knowledge.ts`

| 你实际写的 | 市场 / 面试里管它叫 |
|---|---|
| 向量召回 + 关键词召回两路并行 | **混合检索** Hybrid Retrieval |
| 两路结果按"排名倒数"相加融合（k=60） | **RRF 倒数排名融合** Reciprocal Rank Fusion |
| 再上交叉编码器只对 top-20 精排 | **Rerank / 交叉编码器重排** |
| 没配 key 或接口挂了 → 回退融合结果 | **优雅降级** Graceful Degradation |
| 先按 category / tags 过滤再打分 | **元数据预筛** Metadata Filtering |
| 同一篇文档只留最高分那片 | **去重 / 多样性控制** |
| 发现单字"张"误命中 → 改成必须全中 | **中文分词策略优化** |
| 旧逻辑注释保留供对比 | **消融实验** Ablation |

### ② 工程底座 — `lib/api.ts` / `app/api/login` / `app/api/me`

| 你实际写的 | 市场名词 |
|---|---|
| 所有外部请求收口到一个 `request()` | **统一出口 / 单一数据通道** |
| `AbortController` 10 秒超时 + finally 清定时器 | **超时控制与资源回收** |
| 超时 / 断网 / HTTP 错误全转成中文 | **错误归一化**（面向 LLM 可读） |
| "改域名 / 加鉴权 / 加超时只改这一个文件" | **关注点分离 / 可替换数据层** |
| 访问密码 → `httpOnly` cookie 存 token | **轻量鉴权 / Session 管理** |
| `sameSite: lax` + `maxAge` 7 天 | **Cookie 安全属性配置** |
| 小程序真机 Set-Cookie 不可靠 → 改走 `x-site-token` 头 | **多端凭证适配** |
| EdgeOne 的 `cookies()` 不稳 → 单独 try 兜住 | **平台兼容 / 防御式编程** |
| 环境变量优先，否则注入当前域名 | **部署适配 / 12-Factor 配置** |

### ③ 工作流编排 — `lib/collection-workflow.ts`

| 你实际写的 | 市场名词 |
|---|---|
| 手写 45 行 `while` 循环跑状态图 | **图执行引擎 / StateGraph / Pregel 循环** |
| 节点返回 Partial 打补丁 | **状态归约** Reducer |
| 边是 Map，值可以是函数 | **条件边** Conditional Edge |
| `humanApprove` 只贴 `needsApproval` 不阻塞 | **人机卡点** HITL / Interrupt |
| 查不到就 `throw`，让异常穿出整张图 | **故障传播语义**（失败 = 图不成立） |
| 最外层 `catch` 拦成结构化结果 | **边界降级 / 错误归一化** |
| 外部字段 → 图内字段的独立节点 | **适配器 / 防腐层** Anti-corruption Layer |
| 低风险客户返回"本期不催收" | **业务短路 / 显式状态分支** |

### ④ 工具与协议 — `lib/tool.ts` / `app/api/chat` / `mcp-server/`

| 你实际写的 | 市场名词 |
|---|---|
| 三个只读工具，AI 自主决定调哪个 | **工具调用** Tool / Function Calling |
| 返回值带 `found` / `outcome` / `note` | **工具契约设计 / 上下文工程** |
| `@modelcontextprotocol/sdk` 起 stdio server | **MCP Server**（协议层实现） |
| 换模型只改 `baseURL` | **模型接入抽象**（OpenAI 兼容协议） |
| 一次对话最多 5 步工具往返 | **Agent 循环上限 / 成本闸门** |
| 异常分支省掉 2 次 AI 调用（1.2s vs 7.5s） | **延迟与成本优化** |

### ⑤ 数据与提示 — `data/*.json` / `app/api/chat/route.ts`

| 你实际写的 | 市场名词 |
|---|---|
| 照 ERP 真实表结构造 mock | **数据契约 / 接口对齐** |
| prompt 写清能力边界和红线 | **提示词工程 / 能力声明** |
| 工具改了必须同步改 prompt | **契约一致性维护** |
| 明说"不返回账龄"防模型估数 | **反幻觉设计** |

## 三、可以直接背的五句话

1. **RAG**："知识库用混合检索（向量 + 中文 BM25）+ RRF 融合 + 交叉编码器重排，三级降级保证接口挂了也不整挂。"
2. **人审**："催收动作里的人审不是弹窗等待，是把图切断在 `humanApprove` 节点返回 `needsApproval`——副作用永远不落在图里。"
3. **异常**："工具查不到数据时 `throw` 穿出整张图，在最外层拦成结构化结果交给模型，而不是在节点里降级——否则异常会变成幻觉的原料。"
4. **多端凭证**："浏览器走 httpOnly cookie，小程序因为真机 Set-Cookie 不可靠改走自定义头，两种凭证在一个接口里统一解析。"
5. **翻译层**："外部接口契约和图内契约之间隔了一个独立节点，换数据源只改那一处，不动图结构。"
